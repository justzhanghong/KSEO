# KSEO LOGO

`kseo-logo.png` 是使用内置 imagegen 生成的透明背景工程 LOGO。

- 计算块表示 Kernel。
- 分支路径表示 Scheduling。
- 外围箭头闭环表示 End-to-End 优化和验证。
- 字标保持 KSEO，便于代码仓库与工程文档使用。

生成 prompt：

> Use case: logo-brand. Create the final logo for a new open-source engineering tool named KSEO, whose scope is Kernel, Scheduling & End-to-End Optimizer. Asset type: GitHub repository README and project identity. Create a distinctive, highly simplified geometric emblem paired with the exact wordmark "KSEO" (K S E O, spelled exactly once). The emblem should combine a compact compute/kernel tile, a clean branching scheduling path, and a continuous enclosing path that suggests an end-to-end optimization loop, integrated into one coherent angular mark rather than three separate icons. Professional developer-tool identity, strong silhouette, flat vector-like edges, restrained two-color treatment, bold carefully spaced sans-serif wordmark, generous clear space. Horizontal logo lockup, transparent background, centered composition. No subtitle, no additional text, no watermark, no mockup, no shadows, no gradients, no glowing circuitry.
